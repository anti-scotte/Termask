# TermAsk Workbench 前端项目介绍书

> 版本：v0.1.0（开源发布版） · 适用范围：`termask-workbench/src/` 前端应用
> 配套文档：仓库根 [README.md](../README.md)（产品定位与全景）· [LICENSE-frontend.md](./LICENSE-frontend.md)（前端许可证）

---

## 1. 定位与边界

前端是 TermAsk 的**桌面工作台**（Tauri 2 WebView 内运行的 React SPA），承载五类页面：模板管理、概念图谱、白板、模型设置、设置。

前后端边界清晰：

| 层 | 职责 |
|---|---|
| 前端（本文档） | 页面渲染、交互、状态管理；经 Tauri `invoke` 调后端命令；直接与用户自配的 LLM 服务无关联（LLM 调用一律经后端） |
| 后端（`src-tauri/`，另见后端文档） | 本地桥 HTTP 服务（127.0.0.1:17570，接收浏览器插件推送）、LLM 三协议调用、JSON 数据落盘（登录按用户隔离）、导出渲染 |

前端**不**直接读写磁盘数据文件、不直连任何远程服务（除 Tauri 官方插件）——所有持久化与 LLM 请求都通过后端命令。这保证隐私边界：数据只落本机、凭证只在后端与所选模型服务间传输。

## 4. 契约层：bridge.ts / bridge-ext.ts

前端与后端的全部交互收敛在两个文件，**bridge-ext.ts 是新增契约的权威源**（后端核对契约以它为准；bridge.ts 对其 re-export，避免双份定义漂移）：

- `bridge.ts`：历史批次命令（划词暂存 / 图谱 / 白板 / 账户 / 设置 / 桥接安全 / 全局快捷键）。
- `bridge-ext.ts`：v0.1.0 新增契约——`classify_concepts`（LLM 词语分类）、`get/set_app_preferences`、`get/set_data_location`（数据目录迁移）、`export_graph_project`（六格式导出落盘）、`change_password`、`ask_llm`（自由问答）、`check_app_update` / `install_app_update`（updater）、`write_export_file`（通用导出落盘，前端产物 base64 落盘）、`get/set_smtp_config`（SMTP 邮件）、`get_global_shortcut`。

约定：

1. 字段名与 Rust `#[serde(rename_all = "camelCase")]` 一一对应，类型即文档；
2. 前端对"后端可能未上线"的命令做**能力探测降级**（UI 提示 + 主流程不中断），但不吞错——错误原文透传到界面；
3. 新增契约一律先进 bridge-ext.ts 并附注释说明后端要求。

## 5. 概念图谱（GraphPage）关键设计

- **画布**：React Flow 自定义节点（概念卡/韦恩图区域/纸张边框）+ 自定义边（关系词/解释双标签）。
- **连线交互**：节点内嵌隐形 Handle（仅供边锚点计算，`nodesConnectable=false` 禁用拖线）；连线走节点工具栏「拉线模式」——点按钮后点击目标词框即连，Handle 按两框相对方位自动选择；「AI 连线」复用 `analyze_concepts_relationship` 生成关系词。
- **连线形态**：`orthogonal`（getSmoothStepPath，90° 折线，圆弧半径全局可调，默认）/ `smooth` / `straight` / `sketch`（压感带状笔迹：起收笔收细、中段饱满、seeded 形状恒定，见 sketchyPath.ts 的 ribbonSketchPath）；动态特效经 prefs 全局注入。
- **模板语义**：五套脚手架注入专属形状/图标（如树状=菱形根→圆分支→卡叶；流程图=胶囊起止+菱形判断+返工回路），连线亦带模板语义（tree 用大圆弧正交、flow 用直线+是/否标签）。
- **词库收纳**：画布填词自动登记（防抖保存 effect 内 upsert）；类型识别先用本地启发式 `guessKind`，后端 `classify_concepts` 接入后替换（kindSource 标记 auto/manual）。
- **质量测验**：图谱命题概览投喂 `ask_llm`，强制 JSON 协议 `{score,summary,gaps}`，容错解析，计时 + localStorage 历史（termask-graph-quiz）。
- **导出**：主路径 `export_graph_project`（后端渲染，六格式，按纸张边框裁剪）；旧后端降级为前端管线（graphExport.ts：xyflow 公开路径函数精确重算连线 + Canvas 2D 重绘 PNG）。
- **撤销/重做**：快照栈（HISTORY_LIMIT 50），Delete 删除与各类结构性操作均入栈。

## 6. 白板（WhiteboardPage）关键设计

- **三层结构**：白板文档（可删，软删除标记 deleted，加载时过滤）→ 页序列 `pages[]`（每页独立 canvasType/template/badge，随 JSON 持久化，后端零改动）→ tldraw 快照。
- **新建页向导**：强制选择画布类型（无限/A4/适应屏幕）+ 模板（空白/网格/康奈尔/产婆术/导入模板）+ 页码角标；旧单页数据自动迁移。
- **调色盘**（PalettePanel v2）：自建 react-rnd 悬浮窗替代原生 StylePanel；修复了"样式不生效"的根因（编辑器外部可变实例不触发 React 渲染——改为 store.listen 节流订阅 + 应用后立即刷新）。三种笔型（钢笔/水笔/荧光笔）：tldraw 无全局透明度样式，荧光笔通过监听新建 draw 形状自动写 `opacity=0.35` 实现。
- **导出**：`editor.toImage`（png/svg，bounds=纸张边框裁剪）→ `write_export_file` 落盘；json/md/html 前端组装。
- **与图谱互通**：收集区词条拖入即贴（tldraw 原生 text/plain 流程），选中文字反向入收集区；AI 批注（ai_annotate_whiteboard）关键词一键回收集区。

## 7. 状态与持久化策略

| Store | 持久化 | 说明 |
|---|---|---|
| useGraphStore / useTemplateStore / useModelStore / useAuthStore | 后端命令（save/load_graph_projects 等） | 登录态切换时由 App 层重拉 |
| useSettingsStore | 后端 settings.json（防抖 600ms） | 快捷键等应用级配置 |
| usePrefsStore | localStorage（termask-prefs） | 纯前端视觉偏好，不占后端契约 |
| useWordLibraryStore | localStorage（termask-word-library） | 词库收纳 |

设计原则：**结构性数据走后端**（跨设备/按用户隔离），**瞬时视觉偏好走本地**（零后端成本）。

## 8. 开发与验证流程

```bash
npx tsc --noEmit      # 类型检查（strict，零 noUnusedLocals 容忍）
npx vite build        # 生产构建（后端无需在场）
npm run tauri dev     # 真机回归（需 Rust 后端）
```

- 提交前双绿（tsc + build）是硬性纪律；
- 体积纪律：不引入大依赖（如 lucide 全量 icons、tldraw 内部包），图标用白名单手动 import（components/graph/iconPalette.ts）；
- 代码风格：中文注释 + 每个模块头部"设计要点"块，契约变更必须带注释说明后端要求。

## 9. 已知限制与后续路线（截至 v0.1.0）

1. **真机回归清单**：白板多页切换、荧光笔透明度时机、导出文件渲染验证、SMTP 真实邮件、自动更新（需签名源配置）。
2. **docx/PNG/PDF 导出**依赖后端渲染（系统字体），字体缺失时后端返回可读错误。
3. **词库 LLM 分类**：`classify_concepts` 命令已对接，词库 upsert 处的接入开关待真机联调。
4. **实时交互窗口**（浏览器容器 + 分词高亮 + embedding 对齐）：方案已评审（三期路线），未开工——见交接记录 2026-11-07。
5. **快捷键**：应用内快捷键（N/B/Q/E/T）当前为固定键位，录制式自定义仅覆盖全局快捷键两项。
